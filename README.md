
# Análise Comparativa de Ações

Projeto de análise de dados desenvolvido com Python, utilizando Pandas e yfinance para comparar o desempenho histórico das ações BBSE3, ITSA4 e VALE3.

## Objetivo

Analisar o comportamento das três ações ao longo de 12 meses, comparando rentabilidade, volatilidade e evolução dos preços.

## Tecnologias utilizadas

- Python
- Pandas
- yfinance
- Matplotlib
- Jupyter Notebook

## Indicadores analisados

- Preços de fechamento
- Rentabilidade acumulada
- Retornos diários
- Volatilidade diária e anualizada
- Preços máximos e mínimos
- Retorno por volatilidade

## Principais resultados

A BBSE3 apresentou a melhor relação histórica entre rentabilidade e volatilidade, enquanto a ITSA4 registrou a maior rentabilidade acumulada. A VALE3 apresentou o menor retorno no período analisado.

## Estrutura do projeto

- `analise_comparativa_acoes.ipynb`: notebook com a coleta, exploração, análise e visualização dos dados.
