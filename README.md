
# Análise Comparativa de Ações

Projeto de análise de dados desenvolvido com Python, utilizando Pandas e yfinance para comparar o desempenho histórico das ações BBSE3, ITSA4 e VALE3.

## Objetivo

Analisar o comportamento das três ações ao longo de 12 meses, comparando rentabilidade, volatilidade e evolução dos preços.

## Tecnologias utilizadas

- Python
- Pandas
- yfinance
- Matplotlib
- Jupyter Notebook

## Indicadores analisados

- Preços de fechamento
- Rentabilidade acumulada
- Retornos diários
- Volatilidade diária e anualizada
- Preços máximos e mínimos
- Retorno por volatilidade

## Principais resultados

A BBSE3 apresentou a maior rentabilidade acumulada, de aproximadamente 24,39%, e a menor volatilidade anualizada, de 22,83%.

A ITSA4 registrou rentabilidade de aproximadamente 23,97%, mas apresentou maior volatilidade, de 31,20%.

Já a VALE3 teve a menor rentabilidade entre as ações analisadas, de aproximadamente 0,28%.

## Conclusão

Entre os três ativos analisados, a BBSE3 apresentou o resultado mais interessante, combinando maior rentabilidade com menor volatilidade durante o período estudado.
